# Anti-Productivity Bubbles 説明書（日本語）

[English](README.en.md)

## 概要

**Anti-Productivity Bubbles**（以下 **APB**）は、世界初（たぶん）の**作業効率ダウン用シャボン玉アプリ**です。「生産性（Productivity）に逆らう（Anti）泡（Bubbles）」という、潔いほど身も蓋もない名前が付いています。

昨今、AI がコードを書き、メールを書き、そのうち洗濯もしてくれそうな勢いで、世の中は効率化まっしぐら。みんな効率化に夢中で、ちょっと働きすぎではないでしょうか。そこで発想を逆転しました。**「あえて、あなたの作業を邪魔したらどうなるのか？」**

画面の下からふわふわ昇ってくるシャボン玉が、読みたい文字をぐにゃっと歪ませ、あなたの視線を奪い、「…ちょっと綺麗だな」と手を止めさせます。効率は下がります。心の余裕は上がります。締め切りは知りません。

技術的には、Windows のデスクトップ上にシャボン玉を表示するアプリです。シャボン玉は画面の下から上へゆっくり昇り、玉の内側では背後の画面が光の屈折のように歪んで見えます。接続されているすべてのモニターに表示されます。マウスクリックは透過するので、作業は一応続けられます（効率は落ちますが）。

*作者: どら猫。副作用として、シャボン玉を20分ほど眺めてしまうことがあります。会議に遅刻しても責任は負いかねます。*

## 動作環境

- Windows 10 (バージョン 1903 以降) / Windows 11（64ビット、x64）
- Direct3D 11 に対応した GPU
- 追加のランタイムのインストールは不要です。
- 動作確認済み: Windows 11（x64）。ARM64 と古い Windows は未確認です。

## 使い方

1. zip を好きなフォルダに展開します（`APB.exe` と `settings.ini` を同じフォルダに置きます）。
2. `APB.exe` をダブルクリックして起動します。
3. 終了するには **Esc キー**を押します（初期設定）。タスクトレイのアイコンから終了することもできます。
4. 二重起動はできません。すでに起動している場合はメッセージが表示されます。

> **非常用の終了キー:** `Esc` + `左Shift` + `左Ctrl` を同時に押すと、設定にかかわらず必ず終了します。

シャボン玉はマウスクリックを透過するため、表示中も他のアプリを通常どおり操作できます。

## 表示するシャボン玉の数

玉の数は **1モニターにつき15個**が初期値です。

| モニター数 | 表示数 |
|---|---|
| 1台 | 15個 |
| 2台 | 30個 |
| 3台 | 45個 |

## タスクトレイのメニュー

タスクトレイのシャボン玉アイコンをクリックすると、次のメニューが開きます。

| 項目 | 内容 |
|---|---|
| 一時停止 / 再開 | シャボン玉の表示を止める／再開します |
| 設定を再読み込み | `settings.ini` を読み直します |
| 設定ファイルを開く | `settings.ini` を既定のエディターで開きます |
| Windows 起動時に実行 | ログオン時の自動起動を切り替えます（レジストリの現在のユーザーの Run キー） |
| 終了 | アプリを終了します |

## 設定

`APB.exe` と同じフォルダの `settings.ini` をメモ帳などで編集し、**保存すると1秒ほどで自動的に反映**されます（再起動は不要です）。項目が無い場合は初期値が使われます。値が不正な場合も初期値が使われ、メッセージが表示されます。

| セクション | 項目 | 初期値 | 説明 |
|---|---|---|---|
| Bubbles | Count | 15 | 1モニターあたりの玉の数（1〜64） |
| Bubbles | DiameterMin / DiameterMax | 200 / 300 | 玉の直径（ピクセル）。この範囲でランダムに決まります |
| Bubbles | SpeedMin / SpeedMax | 30 / 60 | 上昇速度（ピクセル/秒） |
| Sway | AmplitudeMin / AmplitudeMax | 24 / 48 | 左右の揺れ幅（ピクセル） |
| Sway | RateMin / RateMax | 0.35 / 0.7 | 揺れの速さ（ラジアン/秒）。大きいほど細かく揺れます |
| Refraction | Strength | 0.55 | 屈折の強さ（0〜3）。0 で屈折なし、大きいほど強く歪みます |
| Input | ExitKey | Esc | 終了キー |
| Power | OnBattery | Normal | バッテリー駆動時の動作。`Normal`（変更なし）/ `Reduce`（フレームレートを下げる）/ `Pause`（非表示にする） |
| Power | BatteryFps | 30 | `Reduce` のときのフレームレート（5〜60） |
| Monitor*n* | Enabled / Count | 有効 / 全体の Count | モニターごとの設定（下記） |

### モニターごとの設定

`[Monitor2]` のように、Windows の「設定 > システム > ディスプレイ > 識別」で表示される番号（`\\.\DISPLAYn` の n）でセクションを作ります。

```ini
; このモニターには表示しない場合は Enabled=0
; Count はこのモニターの玉の数（[Bubbles] Count より優先）
[Monitor2]
Enabled=1
Count=10
```

> INI のコメントは行頭の `;` で書きます。`Enabled=0 ; ...` のように値の後ろにコメントは書かないでください。
### 終了キーの指定

- キー名で指定します。例: `Esc`、`Q`、`F12`、`Space`、`Enter`、`Pause`
- `0x1B` のような16進の仮想キーコードも使えます。
- `+` でつなぐと同時押しになります。最後のキーが終了を実行するキーで、それ以前のキーは押したままにします。

```ini
ExitKey=LShift+Esc
ExitKey=Ctrl+Alt+Q
```

使える修飾キー: `Shift` / `LShift` / `RShift`、`Ctrl` / `LCtrl` / `RCtrl`、`Alt` / `LAlt` / `RAlt`、`Win`。`Shift` のように左右を付けない場合は、左右どちらでも有効です。

> **注意:** 終了キーを変更するときは、必ず覚えておいてください。解釈できないキー名を書いた場合は、安全のため `Esc` になります。終了できなくなった場合は、タスクマネージャーから `APB.exe` を終了してください。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 起動直後にエラーが表示される | Windows のバージョンが対応環境か確認してください。詳細は `%LOCALAPPDATA%\APB\APB.log` に記録されます |
| 何も表示されない | 玉は画面下から出現するため、数秒待ってください。それでも表示されない場合は、`Count` と `DiameterMin` を確認してください |
| 動作が重い | `Count` を減らす、または `DiameterMax` を小さくしてください。モニターが多いほど負荷が増えます |
| 設定が反映されない | exe と同じフォルダの `settings.ini` を編集しているか確認してください。タスクトレイの「設定を再読み込み」も試してください。設定の誤りは `APB.log` に記録されます |
| 「無効な設定」のメッセージが出る | 表示された項目を修正してください。修正するまで、その項目は初期値で動作します |
| ウイルス対策ソフトや SmartScreen に警告された | このアプリはコード署名をしていません。配布ページの SHA-256 と、ダウンロードした zip のハッシュが一致することを確認してください（`Get-FileHash` コマンドなど） |
| 全画面のゲームや動画では表示されない | 排他的全画面のアプリの上には表示できない場合があります。ウィンドウ/ボーダーレスモードをお試しください |

## 既知の制限

- モニター構成や解像度が変わると、約1秒後に自動で再初期化します。再初期化に失敗した場合はエラーを表示して終了します。
- 設定を反映するとき、シャボン玉は最初の配置に戻ります。
- 管理者権限で動いているアプリが前面にあるとき、終了キーが検出されない場合があります（タスクトレイのメニューから終了できます）。

## プライバシー

Windows のキャプチャ機能を使うため、画面全体が常にキャプチャされます。キャプチャしたデータはメモリ上でシャボン玉の屈折の計算にのみ使い、**保存・送信は一切行いません**。ネットワーク通信もしません。記録されるのは動作ログ（`%LOCALAPPDATA%\APB\APB.log`、設定や起動の情報のみ）だけです。
